01 / HARDWARE & UAV
Flight Control Hardware

FMU_F7H7 Flight Controller

Designed the schematic and 6-layer PCB layout in Altium Designer for a UAV flight-control board. The system uses a Kakute H7-class controller configured with ArduPilot firmware and integrates a Time-of-Flight sensor to support stable low-altitude flight behavior.

ToolsAltium Designer · ArduPilot
HardwareKakute H7 · ToF sensor
Focus6-layer PCB · UAV control

02 / COMPUTER VISION
Industrial Vision Prototype

Color Sorting System

Built a computer-vision solution for product color classification on a conveyor using Sipeed MaixCAM Elite and Python-based Maix libraries. The system detects RGB color ranges, can auto-start the vision script, and sends counting data to the controller over UART.

SoftwarePython · Maix
HardwareSipeed MaixCAM Elite
InterfaceUART · RGB classification

03 / IOT & POSITIONING
Connected Positioning System

RTK-GNSS LoRa Base

Deployed a wide-area sensing architecture combining high-precision RTK-GNSS positioning with LoRa communications. A u-blox ZED-F9P base station provides correction data to rover nodes, while the LoRaWAN gateway uses Raspberry Pi Compute Module 5 with RAK5146 and is managed through The Things Network.

GNSSu-blox ZED-F9P · UM960
GatewayRaspberry Pi CM5 · RAK5146
NetworkLoRaWAN · The Things Network
